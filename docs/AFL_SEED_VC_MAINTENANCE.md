# AFL Seed VC Maintenance Log

Date: 2026-05-13

This document records how SeedVC was migrated into `AFL_public`, what was changed, and how to reproduce or maintain the setup later.

## Goal

Move SeedVC out of the standalone `ComfyUI_Seed-VC` plugin and maintain it as part of `AFL_public`.

Reasons:

- Avoid the old plugin label `Seed-VC` appearing on nodes.
- Avoid loading two plugins that both expose or depend on the same `seed_vc` Python package.
- Keep AFL audio tools in one plugin directory.
- Make the SeedVC fixes portable with the AFL package.
- Add AFL-specific controls such as `seed`.
- Add a separate loudness matching node for post-processing converted audio.

## Old Plugin Status

The old plugin was moved out of ComfyUI's active custom node path:

```text
ComfyUI/custom_nodes_disabled/ComfyUI_Seed-VC
```

It is kept as a backup, but ComfyUI should not load it anymore.

The active AFL implementation is now under:

```text
ComfyUI/custom_nodes/AFL_public
```

## Nodes Added

### AFL Seed VC

Node id:

```text
AFL:SeedVC
```

Display name:

```text
AFL Seed VC
```

Category:

```text
AFL/Audio
```

Purpose:

Voice conversion using SeedVC models, maintained inside AFL_public.

Important inputs:

- `source_audio`: audio to convert.
- `ref_audio`: reference voice.
- `seed`: controls SeedVC diffusion noise.
- `steps`: diffusion steps.
- `speed`: length adjustment.
- `inference_cfg_rate`: CFG rate.
- `f0_condition`: enables F0-conditioned model, useful for singing.
- `auto_f0_adjust`: shifts source pitch range toward reference pitch range.
- `pitch_shift`: final semitone shift.
- `max_ref_seconds`: reference prompt trim limit.
- `source_chunk_seconds`: source chunk size.
- `unload_model`: free VRAM after run.

Category:

### AFL Match Audio Loudness

Node id:

```text
AFL:MatchAudioLoudness
```

Display name:

```text
AFL Match Audio Loudness
```

Category:

```text
AFL/Audio
```

Purpose:

Match one audio signal to the loudness of a reference audio signal. This is useful after audio normalization or voice conversion, where the output volume may no longer feel consistent with the original input.

Typical use:

```text
AFL Seed VC output -> audio
Original source audio -> reference_audio
```

Modes:

- `lufs`: preferred, uses `torchaudio.functional.loudness` when available.
- `rms`: simpler RMS matching fallback.

Safety controls:

- `max_gain_db`: clamps the amount of gain correction.
- `peak_limit_dbfs`: prevents clipping by limiting gain if the current peak is too high.

## Seed Implementation

SeedVC uses diffusion / flow matching. The random entry point is the initial noise generated by `torch.randn(...)` in `seed_vc/modules/flow_matching.py`.

The AFL implementation adds `seed` to `SeedVCWrapper.convert_voice(...)` in:

```text
AFL_public/vendor/afl_seedvc_core.py
```

For each chunk, the effective seed is:

```text
seed + chunk_index
```

This makes repeated runs with the same seed more repeatable, while different seeds can change details such as breath, tail sounds, texture, and local stability.

The seed is not expected to radically change the spoken content. It is more like an audio detail variation control than a text-to-image prompt seed.

The implementation uses `torch.random.fork_rng(...)` so the node does not permanently disturb global RNG state for other ComfyUI nodes.

## Previous Fixes Preserved

The AFL version preserves the fixes previously made while getting SeedVC running in this ComfyUI package:

- Replaced temporary audio saving with `soundfile.write` instead of `torchaudio.save`.
- Avoided the broken `torchcodec` DLL path that caused `libtorchcodec_core*.dll` loading errors.
- Avoided importing unused DAC / `audiotools` pieces during node startup.
- Trimmed long reference audio by default to keep the SeedVC context window usable.
- Added chunk-window guards to prevent no-progress loops.
- Added ComfyUI interruption checks in long loops so cancel is more responsive.
- Cleaned temporary audio files after each run.

## VRAM Unload Behavior

SeedVC loads Whisper, DiT, BigVGAN, CAMPPlus, and RMVPE directly inside the custom node. These models are not registered with ComfyUI's standard model manager, so ComfyUI's normal unload button may not release all VRAM by itself.

The AFL version adds a plugin-level unload path:

- `AFL Seed VC` calls `unload_seedvc()` when `unload_model` is enabled.
- `AFL Unload Seed VC` can be run manually to clear the AFL SeedVC singleton.
- `SeedVCWrapper.unload()` moves known modules back to CPU, removes references, runs Python garbage collection, and calls ComfyUI's `soft_empty_cache(force=True)` when available.

Some VRAM may still appear reserved by PyTorch or the CUDA driver after unloading. That reserved memory is not always an active model leak, but it can make the dashboard number look higher until another model needs the memory or the process restarts.

## Recommended Workflow

For spoken voice conversion:

```text
Load source audio
Load reference audio
Normalize both if needed
AFL Seed VC
AFL Match Audio Loudness, using original source audio as reference_audio
Preview / save audio
```

For singing:

```text
Set f0_condition = true
Keep auto_f0_adjust = true as a starting point
Use pitch_shift only when the final result is globally too high or low
```

## Notes On F0 Controls

`f0_condition` enables pitch-aware conversion. It matters most for singing or expressive pitched speech.

`auto_f0_adjust` moves the source pitch range toward the reference voice pitch range. This helps when the source and reference have very different pitch ranges.

`pitch_shift` shifts the final pitch in semitones. Positive values raise pitch; negative values lower pitch.

For normal speech, leave `f0_condition` off unless the result sounds pitch-unstable or you specifically need pitch preservation.

## Maintenance Notes

- Do not re-enable the old `ComfyUI_Seed-VC` plugin while AFL_public SeedVC is active.
- If upstream SeedVC is updated, compare changes against `AFL_public/vendor/afl_seedvc_core.py` and `AFL_public/vendor/seed_vc/`.
- Keep node ids prefixed with `AFL:` to avoid collisions with external custom nodes.
- Prefer adding new AFL controls in `AFL_public/nodes/AFL_seed_vc.py`; only edit vendor code when the model runtime itself needs to change.
- If ComfyUI does not show the new node after edits, restart ComfyUI and refresh the browser cache.
